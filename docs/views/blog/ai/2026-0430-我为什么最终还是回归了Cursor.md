嗨，我是辉哥，一个致力于使用AI技术搞副业的超级个体

近日各式各样的AI Coding工具层出不穷，在重度使用Cursor、Augment、Trae、Kiro、Claud Code后，我最终还是回归到了Cursor配合Claud Code的使用习惯

![](http://cdn.sanghangning.cn/blog/hermes/20260430-191519-9040fb24.webp)

### Trae

字节开源的AI code工具，这个应该是国内比较早发布的ide，现阶段在国内属于比较好用的工具了

如果使用上有安全限制，可以使用国内版本；否则，还是推荐使用国际版，国际版可以支持Claude等大模型，会有质的提升

跟其他ide对比来说，使用同样的大模型，还是会感觉调教差很多，最近在使用上也开始收费了，之前我都是作为备用的工具，现在也基本上不会再使用了

![](http://cdn.sanghangning.cn/blog/hermes/20260430-191520-17bae49b.webp)

### Kiro

亚马逊开源的AI code工具，今年下半年发布的，发布那会还是内测阶段，所以速度非常慢，并且ide的一些交互也是不友好2

但是Kiro支持的spec编程范式还是给我眼前一亮，相比如传统的vibe coding，这种规范模式的编程，能够针对于明确的目标，然后进行任务的拆解去实现，不会过渡发散

但是我使用下来，感觉会过渡设计，实现会更加严谨，对于我希望的产品快速MVP，不是很符合

如果你的项目非常庞大，严谨不允许出错，值得尝试一下这个工具

![](http://cdn.sanghangning.cn/blog/hermes/20260430-191520-16ed58c4.webp)

### Augment

Augment Code由大厂专家组团开发出的一个工具，可以通过插件的方式安装到主流的ide中，使用和体验上都挺不错的，也是可以直接使用最新的大模型

我最喜欢它的命令行功能，不会像Cursor一样经常性的卡住，让其帮我在电脑上安装一些软件也是丝滑流畅。代码质量调教上，感觉还是非常不错的。而且，如果你是java后端开发，习惯了jetBrains的使用，Augment Code就可以直接干活了，强烈推荐

![](http://cdn.sanghangning.cn/blog/hermes/20260430-191520-3d7e4c21.webp)

### Claude Code

这个就是原汁原味的最强AI Coding了，如果不考虑预算，就直接使用了，如果你看不懂代码，就可以直接使用，然后运行看效果了；否则，还是推荐使用ide来搭配使用，vscode或者cursor等都是可以通过插件方式使用Claude Code的

需要注意的是opus的效果是更好，拥有更强的推理能力，但是会消耗更多的token，所以，在一些规划的事项上可以使用，具体的代码实现还是建议切换到Sonnet 模型性价比更加高

总之，除了贵，其他都挺好的

### Cursor

这个ide是自从发布后，我使用最多的，目前也是Claude+Cursor的使用方式，在Cursor中通过插件使用Claude也是非常方便

Cursor的性价比还算不错，ide的使用体验优化得很好。支持各种大模型，日常使用推荐claude-4-sonnet thinking，最好开启max mode模式，加载更多的上下文窗口，另外有一个使用技巧，当claude-4-sonnet thinking一直反复解决不了的bug，推荐切换到gpt-5-high-fast模型，会有意想不到的效果

但是Cursor在windows上有一个很不好的体验，就是在执行一些命令行的时候，偶尔会卡住无法执行完成，有时候需要手动输入几个回车，或者终止后输入继续的提示词来解决，这也是我之前所说的Augment code丝滑的点

![](http://cdn.sanghangning.cn/blog/hermes/20260430-191521-4b18a0e9.webp)

### 总结

当然还有很多的AI code工具，比如codex、Windsurf、Qoder等。总的来说各大ide都依赖于大模型来完成代码的生成，如果你还在纠结，就推荐使用Augment Code和Cursor，代码生成的质量都不错，基本能够满足使用

在vibe coding的时代，可能一个创意点会更加的有价值，对于产品的实现，也建议快速迭代出MVP产品，去验证想法的可行性，而不是抱着完美主义的心态，要代码实现得非常完美才能发布上线
