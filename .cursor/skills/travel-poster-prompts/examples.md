# 示例（精简）

默认把完整 JSON 放在对话里给用户复制即可，不必改仓库。以下仅示意字段覆盖方式；真实生成时应替换为用户当天日历里的 `food` / `scenicSpots` / `trafficNumber`。

## 东京（景点 + 街巷饮食为主）

- `center_panel`：铁塔、涩谷、浅草、秋叶原等叠层。
- `surrounding_panels`：浅草雷门与仲见世、涩谷 SKY 或十字路口人潮、秋叶原电器街、歌舞伎町霓虹、拉面隔间蒸汽与汤匙——**不必**为成田/羽田或山手线单独占满两格；若写城内电车，一句车窗剪影带过即可。

## 吉隆坡（地标 + 南洋饮食；弱化航线）

- `center_panel`：双子塔、独立广场建筑意向、热带天际线。
- `surrounding_panels`：中央艺术坊挑高天井与摊档、独立广场草坪与殖民立面、双子塔仰拍、海脚人/肥肥蟹餐桌、榴莲摊金枕与开壳——**不写**樟宜出发与返杭两段航线各占一格。

若用户坚持要带交通，**航班号、机场、日期** 须与 `trafficNumber` / `timestamp` 一致且通常只占 **≤1** 条分镜；默认仍以地点与美食为主。
